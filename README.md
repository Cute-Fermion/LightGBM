# 多因子选股 + 树模型

基于 XGBoost / LightGBM 等树模型的 A 股横截面选股系统。在每个时间截面上预测股票未来 20 日的相对收益排名，构建多空组合并回测，评估选股能力。

## 项目简介

本项目的核心思路：

1. **因子挖掘**：从行情和财务数据中构建 6 大类 20+ 个选股因子
2. **滚动训练**：用过去 3 年数据训练模型，预测下 1 个月的股票收益排名
3. **组合构建**：按预测值将股票分 5 组，做多 Top 组
4. **回测评估**：考虑交易成本、涨跌停、停牌等真实约束，评估组合表现
5. **归因分析**：用特征重要性和 SHAP 解释模型决策

与现有框架（如 qlib）不同，本项目**全部模块自行实现**，不依赖任何量化框架，以保证对每个环节的完全控制和可理解性。

## 数据来源与范围

### 数据源

使用 **akshare**（免费、无需 token）或 **tushuare**（获取快，需要账号），数据拉取后存为本地 parquet 文件，后续流程直接读本地，不重复请求网络。

### 数据范围

- **股票池**：沪深 300 成分股（可在 config 中切换为中证 500）
- **时间范围**：2018-01-01 至 2023-12-31
- **频率**：日频

### 需要的数据字段

| 类别  | 字段                            |
| --- | ----------------------------- |
| 行情  | 开盘、收盘、最高、最低、成交量、成交额、换手率、涨跌幅   |
| 估值  | PE_TTM、PB、PS_TTM、股息率、总市值      |
| 财务  | ROE、ROA、毛利率、净利率、负债率、流动比率、营收增速 |
| 指数  | 沪深 300 指数收盘价                  |
| 行业  | 申万一级行业分类                      |

###  akshare 免费接口近似处理说明

akshare 免费接口存在以下限制，本项目采用近似方案处理：

1. **历史成分股**：akshare 不提供完整的历史成分股数据，本项目使用当期成分股近似，可能引入约 1-3% 的年化幸存者偏差。
2. **财务数据发布日**：无法获取精确的财报发布日，采用固定延迟假设：
   - 年报（报告期 12-31）→ 延迟 120 天（假设次年 4 月底可用）
   - 半年报（报告期 6-30）→ 延迟 60 天
   - Q1/Q3 季报 → 延迟 30 天
3. **估值数据**：使用 `stock_zh_valuation_baidu`（百度股市通）获取个股估值历史数据，包括总市值、PE(TTM)、PB、PS。该接口不提供股息率数据。

### 数据清洗

- 剔除上市不足 60 日的股票
- 剔除停牌日
- 回测时剔除涨跌停样本

### 爬虫稳定性

akshare 底层为爬虫，可能因超时或限频失败。项目内置了：
- **指数退避重试**：每次失败后等待时间翻倍（最多 3 次）
- **断点续传**：通过 progress 文件记录已下载的股票，中断后重启自动跳过已完成部分
- **本地缓存**：所有数据存为 parquet，已下载的数据不会重复请求

## 因子体系

### 六大类因子

#### 1. 动量类（中期趋势跟踪）

| 因子                   | 计算方式                  | 逻辑     |
| -------------------- | --------------------- | ------ |
| `mom_5d/10d/20d/60d` | 过去 N 日收益率             | 中期趋势延续 |
| `mom_20d_std`        | 过去 20 日收益率标准差         | 动量稳定性  |
| `high_52w_dist`      | 当前价 / 过去 252 日最高价 - 1 | 距高点距离  |

#### 2. 反转类（A 股短期反转效应显著）

| 因子       | 计算方式      | 逻辑         |
| -------- | --------- | ---------- |
| `rev_1d` | 过去 1 日收益率 | 散户过度反应后的反弹 |
| `rev_5d` | 过去 5 日收益率 | 短期反转       |

#### 3. 波动类（低波动异象）

| 因子             | 计算方式                  | 逻辑       |
| -------------- | --------------------- | -------- |
| `vol_20d`      | 过去 20 日日收益率标准差 × √252 | 年化已实现波动率 |
| `atr_14d`      | 14 日 ATR / 收盘价        | 归一化真实波幅  |
| `down_vol_20d` | 过去 20 日负收益标准差 × √252  | 下行风险     |

#### 4. 量价类（资金流向）

| 因子 | 计算方式 | 逻辑 |
|------|----------|------|
| `turnover_rate` | 换手率 | 流动性 |
| `volume_ratio` | 5 日均量 / 20 日均量 | 量比 |
| `vol_price_corr` | 过去 20 日收益率与成交量的相关系数 | 量价配合度 |

#### 5. 估值类（价值因子）

| 因子 | 计算方式 | 逻辑 |
|------|----------|------|
| `ep` | 1 / PE_TTM | 盈利收益率（越高越便宜） |
| `bp` | 1 / PB | 账面市值比 |
| `sp` | 1 / PS_TTM | 营收市值比 |
| `dv_ttm` | 股息率(TTM) | 分红回报 |
| `ln_market_cap` | ln(总市值) | 对数市值 |

使用倒数形式（如 1/PE）而非 PE 本身：PE 为负（亏损）时倒数仍有效，且"便宜"的股票值更大，方向统一。

#### 6. 质量类（基本面质量）

| 因子 | 来源 | 逻辑 |
|------|------|------|
| `roe` | 财务数据 | 盈利能力 |
| `roa` | 财务数据 | 资产回报率 |
| `gross_margin` | 财务数据 | 竞争优势 |
| `net_margin` | 财务数据 | 盈利效率 |
| `debt_ratio` | 财务数据 | 财务安全 |
| `current_ratio` | 财务数据 | 短期偿债能力 |
| `revenue_growth` | 财务数据 | 成长性 |

财务数据为季度频，通过 `merge_asof` 按发布日对齐到日频，确保只使用当时已公布的数据。

### 因子处理流程

```
原始因子 → 去极值（MAD） → 标准化（z-score） → 中性化（市值+行业回归取残差）
```

1. **去极值**：MAD 法，将超过 中位数 ± 3×1.4826×MAD 的值截断
2. **标准化**：横截面 z-score，使均值为 0、标准差为 1
3. **中性化**：对 ln(市值) 和行业哑变量做 OLS 回归，取残差。消除因子与市值/行业的系统性关联，避免模型只学到"大盘股"或"某行业"特征
4. **缺失值**：缺失比例 > 50% 的因子直接剔除，树模型可自动处理剩余缺失值

## 防信息泄露设计

信息泄露是量化项目中最常见的错误，本项目在多个层面做了严格防范：

### 1. 因子计算

- 所有因子**只使用 t 时刻及之前的数据**
- 滚动计算函数（如 `_pct_change_by_group`）通过 `shift(window)` 确保不使用未来数据

### 2. 标签构建

- 标签（未来 20 日收益）虽然使用了"未来数据"，但它是预测目标，不可避免
- 标签仅在训练时使用，预测时不可见

### 3. 时间序列划分（Purge + Embargo）

```
Window 1:  [====train====][embargo][valid]
Window 2:       [====train====][embargo][valid]
```

- 训练集和验证集之间有 embargo 间隔（默认 = forward_days = 20 天）
- 防止训练集的标签与验证集的特征在时间上重叠

### 4. 财务数据对齐

- 财务数据按**估算发布日**对齐，而非报告日期
- 使用 `merge_asof(direction="backward")`，确保每个交易日只使用已公布的财务数据

### 5. 回测约束

- 调仓日使用 t 日收盘时的预测值，t+1 日开盘价成交
- 涨跌停标记：涨停不能买，跌停不能卖

## 模型训练

### 对比模型

| 模型 | 角色 | 特点 |
|------|------|------|
| Ridge 回归 | 基线 | 线性、可解释、快速 |
| 随机森林 | 非线性基线 | 天然处理非线性和交互 |
| XGBoost | 主力模型 | 梯度提升树，内置早停 |
| LightGBM | 主力模型 | 直方图算法，速度快 |

### 训练流程

```
对于每个滚动窗口（共约 70 个）:
    1. 用过去 3 年（756 交易日）的因子和标签训练模型
    2. 用验证集（接下来 20 交易日）做早停
    3. 对验证集生成预测值
    4. 保存模型和预测结果
```

### 早停策略

- **早停指标**：RMSE（与树模型原生优化目标一致，训练更稳定）
- **模型选择指标**：Rank IC（最终评估用）
- 每个窗口重新初始化模型，避免状态残留

### 关键超参数

所有超参数集中在 `config/config.yaml` 中，包括：
- 树的数量、深度、学习率
- 正则化系数（L1/L2）
- 子采样比例
- 早停轮数

## 回测系统

### 组合构建

1. 在每个调仓日（每月一次），按预测值将股票等分为 5 组
2. 默认只做多 Top 组（预测值最高的 20%），可在 config 中切换为多空模式
3. 等权持有（可配置为市值加权）

### 交易成本

| 成本项 | 费率       | 说明                 |
| --- | -------- | ------------------ |
| 佣金  | 买卖各 0.3‱ | 双向收取               |
| 印花税 | 0.5‱     | 仅卖出收取（2023 年 8 月后） |
| 滑点  | 0.1%     | 模拟冲击成本             |

### 真实约束

- **涨跌停**：涨停不能买入，跌停不能卖出
- **停牌**：停牌期间不交易
- **换手率**：根据新旧持仓的交集比例计算实际换手，仅对换手部分收取交易成本

### 输出

- 各组每日收益率
- 累计净值曲线
- 多空收益差

## 评估指标

### 核心指标

| 指标 | 含义 | 参考标准 |
|------|------|----------|
| **Rank IC** | 预测值与真实收益的 Spearman 相关系数 | > 0.03 有选股能力 |
| **ICIR** | IC 均值 / IC 标准差 | > 1.0 较好 |
| **IC 正比例** | IC > 0 的天数占比 | > 55% |

### 收益风险指标

| 指标        | 含义                    | 参考标准          |     |     |
| --------- | --------------------- | ------------- | --- | --- |
| 年化收益率     | 组合年化回报                | —             |     |     |
| 年化波动率     | 收益的标准差                | —             |     |     |
| 夏普比率      | (年化收益 - 无风险利率) / 年化波动 | > 1 不错，> 2 优秀 |     |     |
| 最大回撤      | 从最高点到最低点的最大跌幅         | < 20% 较好      |     |     |
| Calmar 比率 | 年化收益 /                |               |     |     |

### 分组单调性

好的选股模型应满足：Group 5 收益 > Group 4 > ... > Group 1。单调性说明模型在不同分位上都有区分能力，而非仅靠极端值。

## 归因分析

### 特征重要性

从树模型中提取基于信息增益的特征重要性排序，识别对选股贡献最大的因子。

### SHAP 值分析

使用 SHAP（SHapley Additive exPlanations）解释模型预测：
- **Summary Plot**：每个因子对预测的贡献方向和大小
- **Bar Plot**：因子重要性排序（基于 SHAP 绝对值均值）
- 可观察因子是非线性贡献还是线性贡献

### 因子相关性

计算因子间的相关系数矩阵，识别：
- 高度相关的因子对（可能存在冗余）
- 模型是否过度依赖某几个因子

## 配置说明

所有可调参数集中在 `config/config.yaml` 中，代码中不硬编码任何业务参数。主要配置项：

```yaml
# 股票池与时间范围
data:
  universe: "hs300"          # 或 "zz500"
  start_date: "2018-01-01"
  end_date: "2023-12-31"

# 标签
labels:
  forward_days: 20           # 预测未来 20 日收益

# 滚动窗口
split:
  train_window: 756          # 训练集长度（约 3 年）
  predict_window: 20         # 验证集长度（约 1 个月）
  step: 20                   # 滚动步长

# 模型参数（XGBoost / LightGBM 等）
models:
  xgboost:
    n_estimators: 500
    max_depth: 5
    learning_rate: 0.05
    ...

# 回测
backtest:
  n_groups: 5                # 分组数
  long_only: true            # 只做多
  commission_rate: 0.0003    # 佣金
  stamp_tax_rate: 0.0005     # 印花税
  slippage_rate: 0.001       # 滑点
```

修改配置后重新运行对应模块即可，无需改动代码。
